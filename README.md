## The joke

> IT makes me change my password every 90 days, so now it's just the date I last cried at my desk.

96 characters, one line, no wasted setup: a true office observation (everyone who has ever been forced to rotate a password nods), a surprising last word (the password *is* the cry-date), and it reads cleanly aloud in a single breath.

python3 main.py               # writes the joke to /output/entry.txt
python3 main.py --self-test   # validates the gate: 1–200 chars, single line, no padding, UTF-8

`main.py` is the whole entry: it validates the line against the gate, then writes it byte-exact to `/output/entry.txt`. No network, no secrets, no dependencies beyond Python 3.
